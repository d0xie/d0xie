### Проекты

- **[Advertisement API](ссылка_сюда)** — REST API для сервиса объявлений на FastAPI и PostgreSQL. Реализовал CRUD, поиск по параметрам, JWT-аутентификацию и права для пользователей и администраторов. Приложение запускается в Docker.
- **[VK Dating Bot](ссылка_сюда)** — бот для знакомств, которого мы написали вдвоём. Я отвечал за самого бота, включая работу с API ВКонтакте и логику подбора анкет. Базу данных сделал напарник.
- **[Data Parser](ссылка_сюда)** — парсер, в котором я вынес кеширование и логирование в декораторы.
- **[SWAPI Async Loader](ссылка_сюда)** — загрузчик данных о 81 персонаже из Star Wars API. Запросы выполняются асинхронно через `asyncio` и `aiohttp`, а результаты сохраняются в базу.

### С чем работаю

- **Бэкенд** — FastAPI, Django, Django REST Framework, Flask, aiohttp, Celery. REST API, CRUD, JWT-аутентификация и разграничение прав.
- **Базы данных** — SQL, PostgreSQL, pgAdmin, Django ORM и SQLAlchemy, в том числе в асинхронном режиме. Проектирование таблиц и написание запросов.
- **Python** — ООП, модули и пакеты, итераторы, генераторы, декораторы, регулярные выражения и работа с файлами. Асинхронное программирование с `asyncio` и работа с циклом событий.
- **Интеграции** — HTTP-запросы через `requests` и `aiohttp`, внешние API, веб-скрапинг, боты для ВКонтакте и Telegram.
- **Тестирование и запуск** — юнит-тесты, pytest, Git, Docker и Docker Compose. Основы терминала, развёртывания на сервере и CI/CD.
